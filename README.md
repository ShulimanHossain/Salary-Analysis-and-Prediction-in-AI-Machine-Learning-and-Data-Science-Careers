# AI, ML, and Data Science Job & Salary Analysis


## Introduction

This is a practice project focused on applying Data Analysis and Machine Learning techniques to analyze salary trends in Artificial Intelligence (AI), Machine Learning (ML), and Data Science fields.  
The project uses a publicly available dataset from Kaggle that represents real-world job market information.

Through exploratory data analysis (EDA) and machine learning modeling, the goal is to strengthen practical skills in:

- Data preprocessing  
- Feature analysis and visualization  
- Salary prediction modeling  

---

## 📊 Dataset

The dataset used in this project was collected from Kaggle.

- **Name:** Data Science, AI & ML Job Salaries in 2025  
- **Source:** https://www.kaggle.com/datasets/adilshamim8/salaries-for-data-science-jobs  

---

## 📁 Project Overview

The dataset contains job-related information such as experience level, employment type, company size, and remote work ratio.  
These attributes are analyzed to understand which factors have the strongest impact on salary.

The project aims to discover:

- How experience level and employment type impact salaries  
- Which factors most influence pay in AI/ML/Data Science careers  
- Whether company size and company location affect salary levels  

---

## 🧾 Features Description

### experience_level
- **EN** : Entry-level / Junior  
- **MI** : Mid-level / Intermediate  
- **SE** : Senior-level  
- **EX** : Executive / Director  

### employment_type
- **FT** : Full-time  
- **PT** : Part-time  
- **CT** : Contract  
- **FL** : Freelance  

### remote_ratio
- **0** : No remote work (On-site)  
- **50** : Hybrid (partially remote)  
- **100** : Fully remote  

### company_size
- **S** : Small (1–50 employees)  
- **M** : Medium (51–500 employees)  
- **L** : Large (501+ employees)  

---

## 🎯 Objective

To explore, analyze, and visualize key factors affecting salaries in AI, ML, and Data Science roles, and to develop a machine learning model to predict salary based on these attributes.

---

## ⚙️ Tools & Technologies

## 📈 Model Evaluation

The models are evaluated using the following metrics:

- **Accuracy**
- **Mean Absolute Error (MAE)**
- **Mean Squared Error (MSE)**
- **R² Score**

These metrics help measure the performance of salary prediction models.

## ✅ Conclusion

This project demonstrates an end-to-end data analysis and machine learning workflow for AI, ML, and Data Science salary prediction.  
It highlights the importance of experience level, remote work, and company size in determining salary and provides data-driven insights into the job market.

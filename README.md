
# AI, ML, and Data Science Job & Salary Analysis

## Introduction
The rapid growth of Data Science,Artificial Intelligence (AI), and Machine Learning (ML) has created a high demand for skilled professionals worldwide and  salaries for these roles vary different factors such as experience, job title, location, remote ratio, and company size.

This project focuses on analyzing a dataset of ,AI, and, ML job informations to **identify and understand the key factors that influence salary**.
By exploring this dataset, the following insights can be observed:
- How experience level and employment type impact salaries  
- Factors that most influence pay in AI/ML/Data Science related careers   
- Does **company size** and **company location** have an impact on salary levels?



## Objective
To explore, analyze, and visualize key factors affecting salaries in AI, ML, and Data Science roles, and to develop a machine learning model to predict salary.

## Attribute information

### experience_level

    - EN: Entry-level / Junior
    - MI: Mid-level / Intermediate
    - SE: Senior-level
    - EX: Executive / Director

### employment_type

    - FT: Full-time
    - PT: Part-time
    - CT: Contract
    - FL: Freelance

### remote_ratio

    - 0: No remote work (On-site)
    - 50: Hybrid (partially remote)
    - 100: Fully remote

### company_size

    - S: Small(1-50 employees)
    - M: Medium (51-500 employees)
    - L: Large (501+ employees)
